02 / ENGINE

把 1-bit 塞进 CPU 的每一条流水线

Lumina Engine 不只是 Q1_0 的 CPU 内核。它还为量化模型准备了一个 QLoRA 训练器、一个逐字节无损的 GGUF 压缩容器，以及一套会自己判断 CPU / GPU 的调度策略。

核心仍然是为 Bonsai 的 ±1 权重写的：per-128 激活量化、寄存器分块 GEMM、单列 GEMV、二值查表。其余量化类型、后端和模型保持原样。

量化模型也能微调

基座权重保持冻结，只训练低秩适配器；支持 text / messages / conversations 三种数据集、检查点与续训，也能训练 MoE 专家，输出标准 LoRA GGUF。

PACK / .GGUF.LUMINA
更小的文件，字节不变

把 K-quant 字段拆开再压缩，2.63 GB 的 Q4_K_M 模型变成 2.48 GB；解压后 SHA-256 与原文件一致，引擎按魔数自动识别并透明加载。

DEVICE / AUTO
自己决定 CPU 还是 GPU

无 GPU 走纯 CPU；核显跑 dense 模型时把层留在 CPU、算子交给 Vulkan（pp 约 2.4×）；MoE 回到 CPU；独显按显存整层 offload。显式 -ngl 始终优先。

04 / 角色

他们不是吉祥物

埃文和米娅先是 380 的 OC，后来才变成这套工具的两张脸。AI Core 里的两种回答语气，Voice 里的两种声线，Artist 里的两种画风，Animate 里的两个像素小人，最后都会在 AR 里站到同一张桌子上。

CHARACTER SHEET · 01
Ewin 埃文

值班员

蓝头发，猫耳，永远穿那件渐变卫衣。他话不多，负责让东西真的跑起来：Engine 的内核、Core 的调度、AR 里的骨骼。

在 Core 里，他是不绕弯子的那种回答；在 Engine 里，他是终端跑完 256 个 token 后的一行 OK；在 AR 里，他负责把每根骨头放回正确的位置。

CHARACTER SHEET · 02
Miya 米娅

声线与画笔

粉色长发，蝴蝶结，说话像在唱歌。她负责所有需要被听见的部分：Voice 的声线、Artist 的笔触，还有 Core 里那层米娅语气转换。

在 Voice 里，她可以是英语、中文或者日语；在 Artist 里，她先学会自己的脸，再画别人的；在 Core 里，她让回答听起来不那么像机器。
